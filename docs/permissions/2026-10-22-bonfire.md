# Bonfire public metadata permission

On 2026-10-22 the project maintainer explicitly confirmed in the implementation conversation: “As a reminder we have permission to scrape Bonfire as long as we have respectful usage and backoff.” This records the supplied platform permission; it does not infer a licence from anonymous accessibility or robots.txt.

The #110 implementation enables Toronto Public Library's public Open and Past opportunity listing metadata at `https://torontopubliclibrary.bonfirehub.ca`. The Library's own Doing Business page links that portal. The adapter is reusable for other configured Bonfire buyers under #134; enabling another buyer requires checking its source/configuration and recording its inclusion, rather than crawling arbitrary portals.

Respectful use is implemented as serial GETs with at least one second before each request, including retries. A normal successful capture uses three requests: portal landing page, complete Open collection, complete Past collection. There are no per-project requests. Transport errors, 429s and server errors receive at most three retries with exponential backoff. Retry-After seconds and HTTP dates are respected; an instruction to wait more than 60 seconds defers the capture without retrying early. Deferred server deadlines also persist across runs, preventing an immediate manual/scheduled retry from contacting the server early. Other client errors and redirects stop; no account, challenge bypass or login is used.

Raw responses, including empty and error replies, are held before parsing. The portal's robots.txt disallows automated access in general; the maintainer's explicit Bonfire permission above is the authorization for this bounded capture. The linked vendor Terms of Service page was inspected during implementation; its returned body did not include the substantive agreement text. The separately linked Euna EULA concerns its customer subscription and was not treated as a public-data reuse licence. Neither replaces the explicit supplied permission.

Only public listing metadata is enabled here. Documents, bidder identities/submissions, vendor registration, private/invitation-only projects and supplier-facing actions are outside this implementation. Exports credit Toronto Public Library and retain the public source page URL for every listing.
