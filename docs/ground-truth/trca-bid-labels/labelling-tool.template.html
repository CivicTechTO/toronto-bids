Which companies actually bid, and what did they bid?

These are excerpts from real Conservation Authority board reports. We are building a trustworthy answer key so we can measure how well our automated extraction is doing — so please read only what is on the page and record what it actually says. Don't infer, don't tidy up names, and don't guess.

For each excerpt, list every company that submitted a bid.
  1. Company — copy the name exactly as written, including Inc., Ltd., numbered names like 2220742 Ontario Ltd., and any o/a trading name.
  2. Contract / project — which tender or project this bid was for. Many of these documents cover several contracts, so this is what keeps the bids apart. A reference like RFT 10037330 is ideal; the project name is fine otherwise.
  3. Bid amount — exactly as printed, or leave blank if no amount is shown for them.
  4. Outcome — did they win the contract, not win it, or does the text not say?

Tip that saves most of the typing: highlight a name or amount in the document on the left, then press V for company, C for contract, or A for amount and it fills the row you're on.

Ten excerpts each; it should take about twenty minutes. Your work saves as you go, so you can close the tab and come back. Press Export my labels at the end and send the file back.
